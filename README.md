# Зелёный угол — магазин комнатных растений

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Используемые технологии

- HTML5: семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `dialog`, `details`.
- CSS3: переменные в `:root`, Flexbox, CSS Grid, позиционирование, псевдоклассы `:hover`, `:focus-visible`, `:user-invalid`, `:has()`.
- БЭМ-именование классов.
- Git, GitHub, GitHub Pages.

## Выполнение требований

- **Навигация:** единое меню на всех страницах, активный пункт выделен (`site-nav__link--active`, `aria-current="page"`).
- **Карточки:** `article.product-card` с бейджем, названием, описанием, ценой и кнопкой «Подробнее».
- **Таблицы:** `caption`, `thead`, `tbody`, `th`, `td`, оформление в CSS.
- **Формы:** у каждого поля есть `label` с совпадающими `for` и `id`, атрибуты `name`, `required`, `type="email"`.
- **Модальное окно:** `<dialog>` на странице товара.
- **Позиционирование:**
  - `sticky`: шапка, фильтры каталога, блок советов;
  - `relative` + `absolute`: карточка и бейдж;
  - `fixed`: кнопка «Наверх»;
  - `z-index`: шапка, кнопка «Наверх», бейдж.
- **Flexbox:** шапка, меню, группы кнопок, поля формы.
- **Grid:** сетка карточек, раскладка каталога с фильтрами, страница товара, подвал.

## Самостоятельные доработки

1. **Собственное оформление:** зелёная палитра, SVG-иллюстрации растений и логотип нарисованы специально для проекта.
2. **Дополнительные страницы:**
   - `delivery.html`: сравнение способов доставки в таблице, способы оплаты, FAQ на `<details>`;
   - `thanks.html`: сообщение после отправки формы. Формы ведут на неё, так пользовательский сценарий заявки завершён.
3. **Отзывы** покупателей на главной.
4. **Хлебные крошки** на внутренних страницах.
5. **Расширенный каталог:** разделы по категориям, ссылки-якоря на них, sticky-фильтр, отдельные секции.
6. **Варианты карточек через БЭМ-модификаторы:**
   - `product-card--discount`: старая цена;
   - `product-card--sold-out`: товар не в наличии;
   - бейджи `badge--hit`, `badge--new`, `badge--sale`, `badge--muted`.
7. **Вторая таблица:** сравнение комплектаций на странице товара.
8. **Модальное окно** с формой консультации. Закрывается крестиком, клавишей Esc или кликом по фону.
9. **Доступность:**
   - ссылка «Перейти к содержимому»;
   - видимый фокус;
   - `aria-current`, `aria-label`, подсказки к полям через `aria-describedby`;
   - класс `visually-hidden` для скрытых подписей.
10. **Улучшенные формы:**
    - подсветка ошибок через `:user-invalid`;
    - подсказки под полями;
    - выбранный вариант доставки выделяется через `:has()`;
    - кнопка очистки.
11. **Блок «Что будет дальше»** на странице заявки.
12. **Кнопка «Наверх»** с `position: fixed`.
